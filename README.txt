RAVI SINGH PORTFOLIO WEBSITE
============================

Files:
- index.html : Main website
- style.css  : Responsive styling
- script.js  : Navigation, scroll progress, reveal animations
- assets/ravi-singh.png : Profile photo supplied by Ravi
- assets/digicode-logo.jpg : DigiCode IT Solution logo supplied by Ravi

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a modern browser.

HOW TO PUBLISH
Upload the contents of this folder (not the ZIP itself) to your hosting public_html folder.
For GitHub Pages, upload these files to the repository root and enable Pages in repository settings.

IMPORTANT
- The website uses Google Fonts when internet access is available; fallback fonts are included.
- Check all profile details, education status, links and skills before publishing.
- Project art is illustrative; replace it with actual screenshots for completed projects.
