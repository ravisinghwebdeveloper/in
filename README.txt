How to use:

2. Add your images using the exact filenames above.
3. Open index.html in a browser.
4. Upload the whole folder to your hosting/cPanel public_html directory.

Notes:
- LinkedIn button is already connected to the profile URL supplied.
- Contact form opens the visitor's default email application using mailto.
- No backend is required for the current version.
- For a production contact form, connect it to a backend/form service.
